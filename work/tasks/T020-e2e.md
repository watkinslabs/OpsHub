# T020 — E2E

## Identity

- Parent story: `S010` Membership and folders
- Owner: platform
- Branch: `t020-e2e`
- Decision references: `docs/architecture-decisions.md` sections 6, 9; `docs/capability-contracts.md` row F005

## Objective

Build the folder tree, members dialog, and move dialog, then prove the full workspace journey with Playwright, axe, and the 2,000-folder performance lane.

## Specification

- Owned paths: `apps/web/src/features/workspaces/{FolderTree.tsx, FolderTreeItem.tsx, MembersDialog.tsx, MoveFolderDialog.tsx, useTreeKeyboard.ts}`, `testing/features/F005/e2e/workspace.spec.ts`, `testing/features/F005/accessibility/workspace.a11y.spec.ts`, `testing/features/F005/performance/tree_bench.rs`
- Contract/input: generated `WorkspacesApi` (`getTree`, `createFolder`, `updateFolder`, `moveFolder`, `deleteFolder`, `replaceMembers`); query key `['workspace-tree', id]`; `FolderTree` receives `roots`, `tree_version`, and `my_role`.
- Output/behavior: `FolderTree` renders `role="tree"` with `treeitem` and `group` nodes carrying `aria-level` and `aria-expanded`, supports arrow navigation, `F2` rename, `Space`/arrows/`Enter` keyboard move, and drag-and-drop; a move applies optimistically and rolls back on `conflict` or `invalid` (`cycle`, `max_depth`) with an inline error; moves announce `"{name} moved to {parent}"` in a live region; `MembersDialog` edits subject rows with a role select, blocks save when no owner remains, and maps `field_errors.members`; `MoveFolderDialog` offers the tree as a picker excluding the folder and its descendants; viewers see the tree without mutation controls; telemetry `folder_moved`, `members_updated`; the Playwright journey runs against a seeded tenant; `tree_bench.rs` measures the `FolderRepository::load_tree` and `soft_delete_subtree` paths through the API and contains no SQL of its own (decision 2.1), running against the 2,000-folder generator.
- Dependencies: T019 folder, member, and tree routes and their `FolderRepository`/`WorkspaceRepository` queries; T018 shell and dialog conventions; F001 Playwright and axe configuration.
- Feature flag: `F005_FEATURE`
