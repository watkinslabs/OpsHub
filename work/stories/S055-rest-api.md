# S055 — REST API

## Identity

- Parent feature: `F028` API/webhooks
- Owner: platform
- Branch: `s055-rest-api`
- Decision references: `docs/architecture-decisions.md` sections 3, 4; `docs/capability-contracts.md` row F028

## Vertical slice

As a tenant administrator building an integration, I want a generated OpenAPI 3.1 document that matches the running service, scoped rate-limited application credentials, and one set of pagination, filtering, field-selection, error, and correlation conventions on every list route, so that I can build a client from the documentation alone.

## Requirements

- **SR-S055-01:** `GET /api/v1/openapi.json` serves the build-time document generated from `crates/contracts` with every registered `/api/v1` route, DTO schemas, `Error`, `Page<T>`, and security schemes; `check-contracts` fails on drift against `openapi/v1.json` (covers FR-F028-01).
- **SR-S055-02:** `POST/PATCH/DELETE /api/v1/applications` manage applications with scopes, `rate_limit_per_minute`, `allowed_ips`, suspension, and token revocation, publishing `application.updated.v1` (FR-F028-02, FR-F028-03).
- **SR-S055-03:** The `ListQuery` extractor parses `cursor`, `limit`, `filter`, `sort`, `fields`, and `include_total`; invalid cursors and unknown filter fields return `400 invalid` with the named `field_errors` (FR-F028-04).
- **SR-S055-04:** `Page<T>` responses carry `items`, `next_cursor`, `has_more`, optional `total`; `fields` projection always keeps `id` and `version` (FR-F028-05).
- **SR-S055-05:** The `ApiError` mapper and `CorrelationId` layer produce `{ code, message, field_errors, correlation_id }` on every error and echo `X-Correlation-Id` on every response (FR-F028-06).
- **SR-S055-06:** The `RateLimit` layer enforces per-application token buckets with burst 2x and emits `X-RateLimit-Limit`, `X-RateLimit-Remaining`, `X-RateLimit-Reset`, and `Retry-After` on 429 (FR-F028-07).
- **SR-S055-07:** Member actors are denied on application routes, foreign-tenant IDs return `not_found`, and `allowed_ips` rejects other sources (FR-F028-14, NFR-F028-02).
- **SR-S055-08:** The `Applications` and `Reference` pages implement the states in ticket section 3 with a one-time token reveal (FR-F028-15, NFR-F028-03).
