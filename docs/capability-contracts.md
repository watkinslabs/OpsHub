# Capability contracts

Status: FROZEN 2026-09-03, revised for the hand-written backlog. Source: `docs/product-capability-spec.md`; architecture: `docs/architecture-decisions.md`.

Every feature row names its real aggregate, module slug, routes, events, tables, and permission roles. Feature tickets must reproduce every route and event listed here; `cargo xtask check-contracts` fails on drift.

## Conventions

- Module slug `<m>` fixes owned paths: `crates/domain/src/<m>/**`, `services/api/src/<m>/**`, `apps/web/src/features/<m>/**`, `services/api/migrations/*_<m>_*.sql`, `testing/features/F###/**`. Worker/realtime/mcp features add `services/worker/src/<m>/**`, `services/realtime/src/<m>/**`, or `services/mcp/src/<m>/**`.
- All `/api/v1` routes are tenant-scoped by the gateway context; list routes take `cursor`, `limit`, `filter`, `sort`, and `fields`; mutations take `Idempotency-Key` and `If-Match: <version>` and return `version`.
- Errors: `invalid`, `denied`, `not_found`, `conflict`, `rate_limited`, `unavailable`.
- Events are `<aggregate>.<verb>.v1`, published through the outbox with `{ tenant_id, actor_id, aggregate_id, version, changed_fields, correlation_id, occurred_at }`.
- Roles listed are the minimum roles that may perform mutations; reads follow the resource ACL. Deny by default; explicit deny wins.
