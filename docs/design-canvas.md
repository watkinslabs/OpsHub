# Design canvas

The OpsHub design system canvas is the visual source of truth for F062: the token
sheet with every colour, type, spacing, radius, elevation and motion value in both
themes; the component library; the chart and sharing widget sheets; and six reference
screens (sheet grid, dashboard, workflow builder, workload, admin, sharing) in light
and dark, with brand hue and theme as live levers.

Canvas: https://claude.ai/code/artifact/78b6d596-3e4a-4560-a86f-ca4db2c826d2

The canvas is the picture; `work/tickets/F062-design-system-and-ui-primitives.md` is
the contract. When they disagree, the ticket wins and the canvas is corrected.

This file is exempt from the forbidden-token scanner (`support::policy_file`) because
the canvas URL contains a vendor name the scanner rejects. Nothing else in the
repository may carry that token.
